# MacCare

macOS のメンテナンスを 1 つにまとめた個人用アプリ（メニューバー常駐＋ウィンドウ）。
不要データの掃除、大容量ファイルの整理、動画の圧縮、セキュリティスキャン、アプリのアンインストール、ログイン項目の監視を行います。

## できること

| 機能 | 内容 |
|---|---|
| スマートケア | 不要データ・セキュリティ・ログイン項目・大容量ファイルをまとめてスキャンし、結果を 4 つのカードで表示（スキャンでは何も削除しない） |
| クリーンアップ | キャッシュ、ログ、npm／Homebrew／pip のキャッシュ、Xcode の生成物、古い `node_modules`、ゴミ箱。許可リスト方式で、実行中アプリのキャッシュなどは除外 |
| 大容量ファイル | 閾値以上のファイルを一覧。Finder で表示、ゴミ箱へ、動画は圧縮キューへ |
| 動画圧縮 | `ffmpeg`（HEVC・ハードウェアエンコード）で圧縮。長さ・コーデック・サイズを検証してから元ファイルをゴミ箱へ移動 |
| アプリケーション | アプリと関連ファイルをまとめてゴミ箱へ。アンインストール済みアプリの残骸候補も表示 |
| ログイン項目 | LaunchAgents／LaunchDaemons を一覧し、前回からの新規・変更を検出して通知 |
| セキュリティ | XProtect・Gatekeeper・SIP の状態表示と、YARA（XProtect ルール）／ClamAV によるスキャン |
| 定期実行 | 週 1 回（間隔は設定可）、スマートケアを自動実行して通知。自動での削除はしない |

## インストール

必要なもの: macOS 14 以降、Xcode Command Line Tools（`xcode-select --install`）、Homebrew。

```bash
git clone https://github.com/withfox-fox1/mac-care.git ~/mac-care
cd ~/mac-care
./install.sh              # yara / clamav / ffmpeg の導入、ClamAV 設定、ビルド、/Applications へ配置
./install.sh --app-only   # アプリだけビルドして入れ直す
```

- Homebrew が無い場合は自動ではインストールせず、公式のインストールコマンドを表示して終了します。
- 何度実行しても安全です（導入済みの項目はスキップします）。
- Claude Code に導入させる場合は [SETUP_PROMPT.md](SETUP_PROMPT.md) を渡してください。

### 更新

```bash
cd ~/mac-care && git pull --ff-only && ./install.sh --app-only
```

### アンインストール

```bash
./uninstall.sh
```

アプリとログイン項目の登録を削除します。設定・履歴（`~/Library/Application Support/MacCare`）は確認のうえ削除します。
Homebrew のパッケージは削除しません。不要なら `brew uninstall yara clamav ffmpeg` を実行してください。

## 権限

- **フルディスクアクセス（任意）**: ゴミ箱の中身の確認と「ゴミ箱を空にする」に必要です。許可しなくても他の機能は動作します。
- **デスクトップ／書類／ダウンロードへのアクセス**: セキュリティスキャンや大容量ファイル検索の初回に macOS が確認を表示します。
- **通知**: 定期スキャンの結果や新しいログイン項目の通知に使います。
- **オートメーション（Finder）**: 「ゴミ箱を空にする」の初回に確認が表示されます。
- 管理者権限は要求しません。`/Library` など管理者権限が必要な項目は表示のみです。

## 安全設計

- **許可リスト方式**: 掃除の対象はリストにあるパスだけです。リスト外には触れません。
- **削除はゴミ箱へ移動**: `FileManager.trashItem` のみを使い、完全削除はしません（ゴミ箱を空にする操作を除く）。
- **確認ダイアログの既定はキャンセル**: Return キーでは実行されません。実行ボタンを明示的にクリックする必要があります。確認で見せた内容だけを実行します。
- **拒否リスト**: システムフォルダ、ホーム直下の主要フォルダ自体、iCloud Drive、キーチェーン、メール、写真ライブラリなどは、許可範囲内であっても削除できません。
- **許可範囲を機能ごとに限定**: 例えばアンインストールの関連ファイルは検索した各サブフォルダ内に限ります。
- 外部への送信はありません（ClamAV の定義ダウンロードを除く）。

## 制限

- ウイルスの**常時監視はしません**。常時保護は macOS 標準の XProtect／Gatekeeper が担当します。
- ClamAV のスキャンは標準で `/Applications` を除外します（時間短縮）。設定の「じっくりスキャン」で含められます。
- 管理者権限が必要な削除、RAM 解放、ブラウザの履歴削除、アプリの一括アップデートには対応しません。

## 開発

```bash
./test.sh          # Core 層のテスト（XCTest 不使用、Command Line Tools だけで実行可能）
./build.sh         # build/MacCare.app を作成
./build.sh install # /Applications へ配置して起動
```

仕様・進捗・設計判断は [docs/](docs/) を参照してください。
