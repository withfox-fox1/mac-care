# 決定事項

| 日付 | 決定 | 理由 | 不採用案 |
|---|---|---|---|
| 2026-10-14 | CleanMyMac は自作版完成後に解約する前提 | このMacでは掃除の効果が小さく（3〜5GB）、ウイルス対策も標準＋無料ツールで代替できるため | 併用継続、ウイルス対策のため残す |
| 2026-10-14 | 形態はメニューバー＋ウィンドウ | 状態の常時表示と、一覧を見て選ぶ作業の両方が必要 | メニューバーのみ（一覧が見づらい）、CLI のみ |
| 2026-10-14 | ウイルス対策は XProtect（常時）＋YARA(XProtectルール)/ClamAV（手動・定期スキャン） | 無料・オフラインで動作確認済み。CleanMyMac（Moonlock）のエンジンや定義は非公開・規約上流用不可 | CleanMyMac のロジック流用、商用 AV |
| 2026-10-14 | 削除は常にゴミ箱経由、対象は許可リスト方式 | 誤削除を戻せるようにするため | `rm` による即時削除、除外リスト方式 |
| 2026-10-14 | 定期実行はスキャンのみ自動、削除は手動 | 誤削除リスクの回避 | 安全な不要データの自動削除 |
| 2026-10-14 | 動画は HEVC（VideoToolbox, -q:v 50）で圧縮し、検証後に元をゴミ箱へ | テストで約84%削減・SSIM 0.993・目視差なし | 一覧表示のみ、外部への移動 |
| 2026-10-14 | 別の Mac にも導入できるよう GitHub＋SETUP_PROMPT.md で配布 | ユーザー要望。menubar-meters と同じ運用 | このMacのみ |
| 2026-10-14 | ビルドは swiftc＋build.sh（Xcode プロジェクトなし） | menubar-meters と構成を揃え、別 Mac では Command Line Tools だけでビルドできるようにする | Xcode プロジェクト、SwiftPM |
| 2026-10-14 | v1 は管理者権限を要求しない | 権限周りの複雑さとリスクを避ける。必要な箇所は表示＋システム設定への誘導 | 特権ヘルパー（SMJobBless 等） |
