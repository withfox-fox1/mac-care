# MacCare ロードマップ

各フェーズの終わりに実機で動作確認し、結果を PROGRESS.md に記録してから次へ進む。

| # | フェーズ | 内容 | 完了条件 |
|---|---|---|---|
| P0 | 土台 | リポジトリ作成、`build.sh`、メニューバー＋空ウィンドウ（サイドバー）、設定・履歴の保存層、外部コマンド実行ヘルパー、依存ツールの検出 | ビルド・起動でき、メニューバーとウィンドウが開く。依存ツールの有無が表示される |
| P1 | クリーンアップ | 許可リスト、サイズ集計、選択してゴミ箱へ、履歴記録 | 許可リスト外を触らないテストが通る。実機で集計値が `du` と概ね一致 |
| P2 | 大容量ファイル＋動画圧縮 | ファイル検索・並び替え、圧縮キュー、検証付き変換 | 短い動画で変換→検証→元をゴミ箱、の一連が成功。検証失敗時に元が残るテストが通る |
| P3 | セキュリティ | XProtect 状態表示、YARA/ClamAV スキャン、定義更新、検出時の操作 | EICAR を検出。Downloads のスキャン結果が CLI 実行時と一致 |
| P4 | アプリ・ログイン項目 | アンインストーラ（関連ファイル検索）、残骸一覧、ログイン項目一覧・無効化・差分検知 | テスト用ダミーアプリで関連ファイルが全て見つかり、ゴミ箱へ移動できる |
| P5 | スマートケア＋定期実行 | 一括実行、結果画面、週1スケジューラ、通知、メニューバーの状態表示 | 手動実行と定期実行の両方で通知が出る |
| P6 | 仕上げ・配布 | UI 調整、レビュー（Fable 級）、`install.sh`、`SETUP_PROMPT.md`、README、GitHub へ push | 新規ユーザー環境相当で install.sh が通る |
| P7 | 移行 | CleanMyMac を止めて1週間運用 → 問題なければ解約 | 完成条件 6 を満たす |

## 依存関係

- P1〜P4 は P0 のみに依存（並行可能だが、同じファイルを触るため順番に実施する）。
- P5 は P1・P3・P4 に依存。
- P2 の動画圧縮は ffmpeg が必要（このMacは導入済み）。

## 実際の動画圧縮（56GB）について

アプリ完成後（P2 完了後）、まず1本で確認してもらってから残りを処理する。約1.7倍速のため、全量で数時間かかる見込み（夜間実行を推奨）。
